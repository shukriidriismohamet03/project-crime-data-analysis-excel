# 🚔 Crime Data Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing crime data using **Microsoft Excel**. The goal is to clean, organize, analyze, and visualize crime records to identify important patterns and insights related to crime types, districts, case status, severity levels, and victim gender.

The project demonstrates fundamental **Data Analysis skills**, including data cleaning, data transformation, pivot tables, Excel formulas, and dashboard creation.

---

## 📂 Dataset Information

The dataset contains crime records with the following main columns:

* **Crime_ID** – Unique identification number for each crime record
* **Crime_Date** – Date when the crime was recorded
* **Crime_Type** – Type of crime
* **District** – District where the crime occurred
* **Victim_Gender** – Gender of the victim
* **Case_Status** – Current status of the case
* **Severity_Level** – Level of crime severity

The original dataset contained **300 records**. After data cleaning and processing, the cleaned dataset contains **292 records**.

---

## 🧹 Data Cleaning Process

The following data-cleaning steps were performed:

* Identified missing values in the dataset
* Handled missing and unknown values
* Checked for duplicate records
* Standardized inconsistent text values
* Created data quality flags
* Added record status indicators
* Prepared the dataset for analysis

Additional calculated columns were created, including:

* **Crime_Year**
* **Crime_Month**
* **Crime_Month Name**
* **Data_Quality_Flag**
* **Duplicate_Flag**
* **Record_Status**
* **Concatenated Fields**

## 📊 Data Analysis

The analysis explored several important areas:

### 🔹 Crime Type Analysis

The project analyzes the frequency of different crime types, including:

* Theft

* Traffic Offense

### 🔹 District Analysis

## 📈 Key Findings

Some of the major insights from the analysis include:

* **Theft** is one of the most frequently recorded crime types.
* **Hodan** has the highest number of recorded crime cases among the districts in the cleaned dataset.
* **Medium-severity crimes** represent the largest category of crime severity.
* A significant number of cases have been **Closed**.
* Some cases remain **Under Investigation**, showing areas that require continued attention.
* The analysis highlights differences in crime distribution across districts and categories.
